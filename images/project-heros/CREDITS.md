## Processing

All source images were downloaded at full available resolution, resized so the shorter edge covers 1920 x 1080 (preserving aspect ratio), then center-cropped to 1920 x 1080. Saved as progressive JPEG at quality 85.

Four of the five sources (chapters 11, 12, 13, 14) have native resolution well above the target, so the output is a clean downscale with no upscaling artifacts. Chapter 15 (Oxford students) is close to target at the native resolution.
