## Processing

All source images were downloaded at full available resolution, resized so the shorter edge covers 1920 x 1080 (preserving aspect ratio), then center-cropped to 1920 x 1080. Saved as progressive JPEG at quality 85. Processing script lives inline in the commit history and is not kept as a separate file (one-off work).
